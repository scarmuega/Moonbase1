## Reproduce delivery

From the workspace root:

```sh
python3 tools/prepare_hab_model.py /path/to/source/hab-v2.glb
python3 tools/prepare_hab_model.py --check /path/to/source/hab-v2.glb
```

The script requires the exact source hash, changes only the scene-root name
`hab-v2` → `hab`, and preserves all geometry/texture binary chunks byte-for-byte.
`--check` verifies exact delivery equality, embedded buffers/images and valid
UV bindings. It does not rewrite the asset. The source candidate is never edited.

Measurements: 37,600 triangles, 15 mesh primitives, 4 opaque PBR materials,
3 embedded 1024² PNG textures, 3.41 MiB, bounds 13.68 × 14.0 × 7.0981 m,
minimum Y ≈ 0, centred X/Z. Mechanical verification against the domain
`solution/3d-assets/scripts/check_glb.py --height 14 --footprint-radius 8`
passes without changing that validator. Orientation remains +Y up / −Z front.

## Deliberate preview exception

The full deployed study is **14 m tall**, including lander and solar mast, rather
than the catalogue's 5 m primitive proxy. The narrow integration plan authorizes
this experimental exception, not a revision to the shipping asset contract.
No scaling or geometry edits are applied. Catalogue footprint radius 8 m, slope
8°, crew 4, and all power/gameplay values are unchanged. Ghosts still use the
legacy primitive proxy. Model roots use zero half-height lift; primitives retain
their centre-origin lift, both grounded by the shared terrain height field.

Scene-child picking walks to the owning structure, preserving details. Model
selection uses a footprint gizmo instead of modifying shared PBR materials.
The presentation sun follows the terrain's live azimuth/altitude. A modest
stylized ambient bounce makes shaded fabric/hardware readable; it is not physical
lunar atmospheric lighting. The existing custom terrain shader **does not receive
model cast shadows**; shadows are not baked into any texture. This experiment
does not redesign the terrain renderer.

capture commands, performance evidence and verification.
